# 3D 图像合成方法 (3D Image Synthesis Methods)

针对基恩士 (Keyence) 和西克 (SICK) 3D 相机拍摄的原始深度图与强度图，提出了一种优化的图像合成算法，将工业 3D 轮廓数据转化为适用于深度学习缺陷检测的高质量三通道训练图像。

---

## 概述

工业 3D 相机（线激光轮廓仪）同时输出两幅图像：

- **深度图**（16 位无符号 TIFF）—— 物体表面的高度信息，0 值表示无效/背景像素
- **强度图**（8 位灰度 PNG）—— 同一视角的反射率/纹理信息

本算法将两者融合编码为 **3 通道 BGR 伪彩色图像**，每个通道分别编码表面的不同物理维度，使深度学习模型能更有效地学习缺陷特征。

---

## 三通道编码方案

| 通道 | 名称 | 编码内容 |
|------|------|----------|
| **B**（蓝色） | 强度纹理通道 | CLAHE 自适应直方图均衡化增强后的强度/纹理信息 |
| **G**（绿色） | 缺陷增强通道 | 多尺度 Top-Hat + LoG 融合，凸起 > 128（偏亮），凹陷 < 128（偏暗） |
| **R**（红色） | 全局形状通道 | 去趋势后的中尺度表面地形（移除基准面曲率的残差） |

---

## 核心算法流程

1. **输入清洗** — 校验 dtype，安全转换 uint8/uint16 不匹配
2. **无效区域填充** — 掩膜感知高斯滤波填充深度空洞（sigma=24）
3. **去趋势（移除基准面）** — 大尺度高斯估计（sigma=60）并减去，保留中尺度形状
4. **行偏移校正** — 消除线扫描相机的行方向条纹噪声（逐行中位数校零）
5. **MAD 归一化** — 基于中位数绝对偏差的鲁棒归一化（对异常值不敏感）
6. **三通道合成** — 分别提取形状/缺陷/强度特征，融合为 BGR 图像

## 使用方法

### 基恩士相机

```bash
python main-基恩士.py
```

- 读取 `word_2.tiff` + `word_2.png` → 输出单通道灰度 PNG
- 加权融合：`0.7 × 强度 + 0.3 × 深度特征`

### 西克相机 — 单图 API（快速版，推荐）

```python
from synthesize-fast-单图-西克 import synthesize, synthesize_from_path

# 方式一：传递 numpy 数组
result = synthesize(depth_uint16, intensity_uint8)

# 方式二：从文件路径读取
result = synthesize_from_path("depth.tiff", "intensity.png")
# 返回 H×W×3 uint8 BGR 图像
```

### 西克相机 — 批量处理（快速版）

```bash
python synthesize-fast-多图-西克.py --input ./imgs/ --output ./results/
```

### 西克相机 — 批量处理（旧版，含调试视图）

```bash
python synthesize-旧-多图-西克.py --input ./imgs/ --output ./results/ --no-debug
```

旧版批量处理会生成：
- 各通道独立保存的图像
- 缺陷叠加可视化（凸起标注为红色，凹陷标注为蓝色）

## 快速版 vs 旧版（西克脚本）

| 改进点 | 旧版 | 快速版 |
|--------|------|--------|
| 输入容错 | 无 dtype 校验 | `_ensure_depth16` / `_ensure_intensity8` 自动转换 |
| 行偏移校正 | `for` 循环逐行处理 | `np.nanmedian` 向量化，加速 ~30× |
| 大 sigma 高斯 | 全分辨率卷积 | 下采样后卷积（sigma≥16），加速 5-10× |
| MAD 归一化 | 无兜底 | `mad < 1e-3` 时退化为标准差，防止平坦区域噪声放大 |

**建议：新项目直接使用快速版。**

## 关键参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `sigma_baseline` | 60.0 | 基准面估计的高斯核尺度 |
| `sigma_fill` | 24.0 | 无效区域填充的高斯核尺度 |
| `erode_px` | 8 | 掩膜腐蚀像素数（避免边缘伪影） |
| `k_mad` (R 通道) | 6.0 | 形状通道 MAD 归一化范围 |
| `k_mad` (G 通道) | 4.0 | 缺陷通道 MAD 归一化范围 |
| `th_radii` | (5, 11, 21) | Top-Hat 形态学结构元素半径 |
| `log_sigmas` | (1.2, 2.0, 3.0) | LoG 缺陷检测尺度 |
| `clip` / `tile` (CLAHE) | 3.0 / 16 | CLAHE 对比度限制和瓦片大小 |
